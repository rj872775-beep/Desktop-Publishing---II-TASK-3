# Desktop-Publishing---II-TASK-3
Place each photograph on a separate layer.
Rename the layers appropriately, such as Mountain, Lake, Forest, and Background.
Use the Move Tool (V) to adjust image positions.
Press Ctrl + T to resize, rotate, or transform images.
Add a suitable background using a solid color or gradient.
Select an image layer and click Add Layer Mask.
Use the Brush Tool (B) with black and white to hide or reveal image portions.
Use a soft brush or Gradient Tool to blend photographs.
Select the Type Tool (T) and add a suitable title and supporting text.
Double-click the title layer to open Layer Style.
Apply a Drop Shadow, Stroke, or Outer Glow effect.
Adjust colors, alignment, and spacing to improve the composition.
Save the project as Travel_Poster.psd using File → Save As.
Export the final composition using File → Export → Export As in JPEG or PNG format.
